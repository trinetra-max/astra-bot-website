BEFORE PUBLISHING:
1. Open index.html in a text editor.
2. Search for and replace these placeholders:
   - ADD_YOUR_USDT_WALLET_ADDRESS
   - ADD_CONFIRMED_NETWORK
   - YOUR_TELEGRAM_USERNAME
3. In the Telegram link, replace YOUR_TELEGRAM_USERNAME with your real public Telegram username (without @ in the URL).
4. Confirm the wallet address and network carefully. Never publish a guessed address.
5. Make sure your product file is ready and you can manually verify transactions before delivering it.

4. Open the URL on your phone and test all links before sharing it.
